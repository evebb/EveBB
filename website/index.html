Forum software that's fast, light and yours to keep

eveBB is free, open-source forum software for your website — the modern continuation of FluxBB, rebuilt for today's PHP. Fewer features, faster pages, and code you can actually read.

Why eveBB

Everything a forum needs. Nothing it doesn't.

FluxBB earned its reputation by being lean and quick. eveBB keeps that philosophy and brings the engine up to date.

Runs on modern PHP

Fully compatible with PHP 8.1–8.4. Bcrypt password hashing with transparent migration of legacy hashes, CSPRNG entropy throughout.

Your database, your choice

MySQL/MariaDB, PostgreSQL — or SQLite, so a small board runs from a single file with no database server at all.

Security, layered

Per-form CSRF tokens, SameSite cookies, login rate-limiting, a registration CAPTCHA, and SHA-256-verified update packages.

One-click updates

The forum updates itself from the official releases — download, checksum verification and file replacement all handled from the admin panel.

Visual editor built in

A WYSIWYG editor with BBCode under the hood, emoticons and all — no plugins to hunt down.

Reads well everywhere

A mobile-friendly layout and the clean Carbon style out of the box, with the classic style system for full control.

FluxBB boards move in

The database schema is fully compatible with FluxBB 1.5 — switch an existing board to eveBB in place, no migration scripts.

Honestly tested

Unit tests, a database contract suite and end-to-end tests covering install, posting, search and upgrades — run on every change.

Plugins & hooks

Extend the forum through the flux_hook plugin system, and restyle it by dropping a CSS file into style/.

Get started

Online in five minutes

No build steps, no framework stack, no command line required — it's the classic upload-and-go install.

Download the latest release

Download the latest release package — one click, no account needed (all releases). Verify it if you like: sha256sum -c evebb-*.zip.sha256.

Upload the files

Unzip and upload to your web server — any ordinary PHP 8.1+ host works, no special modules needed.

Run the installer

Open install.php in your browser, pick a database (or choose SQLite and skip the database server entirely) and follow the steps. The wiki covers every option in detail.

That's it

Delete install.php, pick a style, open registration. Future updates are one click in Admin → Maintenance.
